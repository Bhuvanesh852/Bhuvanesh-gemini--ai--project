Apex Growth Solutions - Executive Marketing Dashboard (2025–2026)An executive-level, interactive marketing analytics dashboard built for Apex Growth Solutions Inc. This platform processes cross-year performance data across 2025 and 2026 to deliver actionable business intelligence, dynamic KPI tracking, multi-channel ROI analysis, and conversion pipeline breakdown.🌟 Key FeaturesExecutive KPI Monitoring: Real-time visibility into Attributed Revenue, Customer Acquisition Cost (CAC), Lead-to-Win Conversion Rates, and Marketing Spend.Dynamic Year Filtering: Interactively toggle between 2025-2026 (All Data), YTD 2026 Focus, and FY 2025 Full Year.Granular Timeframe Aggregation: Switch between Monthly and Quarterly view modes dynamically on performance charts.Interactive Multi-Touch Funnel: Complete conversion pipeline tracking from impressions down to closed-won deals.Channel ROI Breakdown: Donut chart visualizing spend and returns across Digital Ads, Content SEO, Email, and Events & PR.Top Performing Campaigns Table: Detailed performance indicators including revenue generated, ad spend, and percentage ROI.Glassmorphism Dark Theme: Obsidian dark background enhanced with glowing neon accents (cyan, purple, emerald, rose) and smooth UI animations.🛠️ Built WithMarkup & Structure: HTML5Styling & Design Token System: Tailwind CSS (Custom Animation Keyframes)Data Visualization: Chart.js v4Iconography: Font Awesome 6 (Free)Typography: Plus Jakarta Sans (Google Fonts)📂 Data SourcesThe dashboard aggregates data derived from the official company dataset Marketing Business Data.xlsx across four main operational sheets:Sheet NameDescriptionKey MetricsBusiness_KPIHigh-level monthly enterprise performanceRevenue, Expenses, Net Profit, Retention %Marketing_DataCampaign-level ad spend & conversion metricsLeads, Clicks, CTR %, Spend, ROI %Sales_DataOrder-level sales performanceCustomer Segment, Sales Rep, Units, ProfitCustomersAccounts & Customer Lifetime Value (CLV)Acquisition Channel, CLV, Satisfaction Score🚀 Getting StartedPrerequisitesTo view and run this project, all you need is a modern web browser (Chrome, Firefox, Safari, Edge). No complex Node.js or backend dependencies are required!Quick SetupClone the repository:git clone [https://github.com/bhuvanesh/apex-growth-marketing-dashboard.git](https://github.com/bhuvanesh/apex-growth-marketing-dashboard.git)
Navigate to project directory:cd apex-growth-marketing-dashboard
Open dashboard.html in your browser:Double-click dashboard.html in your file explorer, ORRun a light local server (e.g., using VS Code Live Server extension or Python http.server):python -m http.server 8000
Open http://localhost:8000/dashboard.html in your web browser.💻 Dashboard Screenshot & Structure.
